# Mini-ACMED
## Build an ISIC Coding Model in 15 Minutes

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/dmatekenya/isic-classifier-demo/blob/main/notebooks/mini_acmed_demo.ipynb)

1. **Open the notebook:** click the badge above and sign in with any Google account.
2. **Connect:** click **Connect** at the top right of Colab and wait for the green tick
   (it takes a few seconds). This starts a free cloud computer to run the notebook.
3. **Run one cell at a time:** click a cell and press **Shift + Enter**, or click the ▶ button
   on its left. Read the explanation above each cell before you run it. Colab moves you to the next cell
   automatically. The first time, Colab may warn that *"This notebook was not authored by Google"*:
   click **Run anyway**.
4. **If you fall behind:** click **Runtime → Run all** to catch up. The whole notebook runs in under a minute,
   and nothing needs installing.
5. **Keep your own copy:** use **File → Save a copy in Drive**. Your changes won't affect the original.
